Modular Cabinet — UX Case Atlas

Every UX scenario for the modular cabinet system (packages/nodes/src/cabinet) — what is implemented, what is partial, what is not implemented yet, and what the industry (IKEA Planner, 2020 Design, Chief Architect, Cabinet Vision, Mozaik, ProKitchen, Winner, HomeByMe, Planner 5D…) does that we should consider. Each case has a simple 2D diagram: PLAN = top-down, ELEV = front elevation. Click a status pill to filter. Generated 2026‑08‑26 from the code on t3code/improve-kitchen-cabinets.

Sources: cabinet package source + tests (run-ops, run-layout, tool, wall-snap, stack, panel, quick-actions, floorplan, validation…), and public feature documentation of the listed industry tools. NKBA numbers are from the 5th-edition planning guidelines summary.
