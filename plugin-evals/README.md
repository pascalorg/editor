# Publishing evaluation fixtures

`publishing-cases.json` is the review suite for Pascal's OpenAI **With MCP** submission. It lists what is `ready` in this repository and the `blockers` that remain, each naming its owner, and holds exactly the five positive cases (prompt, expected tools, expected behavior, result shape, and reviewer fixture) and three negative cases (with the reason the plugin must not act) that OpenAI's initial MCP review takes. `tool-annotation-justifications.json` records the three required hint values and a justification for every hint on all 106 tools the `@pascal-app/mcp` package registers when the host supplies its hosted service and project file executors, as the hosted server does. Repository policy tests check its exact inventory and shape, and the live MCP regression test checks its values, and that every tool has a title, against `tools/list`. The hosted server's hosted-only Capture tools live outside this repository and stay outside this packet.

The ChatGPT ZIP is built with `bun run plugin:chatgpt`, which stages `packaging/chatgpt/mcp.json` (the hosted OAuth server) as its root `mcp.json` and includes only `plugin.json`, `LICENSE`, the listing icons, and the `pascal-3d` and `furniture-fit` skills; the repository root `mcp.json` stays the local server for Codex Git-marketplace installs. The suite stays `blocked` until a verified OpenAI developer identity is selected, the portal's domain challenge passes, the portal tool scan passes, and a reviewer account with the named disposable fixtures exists. Each standalone skill also bundles:

- `evals/evals.json` for task behavior;
- `evals/trigger-evals.json` for description routing, with at least five positive and three negative queries.

The shared suite and annotation packet live outside `skills/` because they are submission evidence rather than skill runtime content. The cases are entered in the portal's Review details rather than declared in `plugin.json`, because each must be run with the reviewer account before submission. No portal scan, domain verification, publisher verification, submission, approval, or publication is represented here.
