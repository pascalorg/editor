## Task 4 — import a vector PDF plan set (optional, high value)

`docs/reference/plancrafters/planset.cjs` is a pure, dependency-free reader
(35 headless checks in `dev-planset-test.cjs`) that turns a CAD-exported PDF set
into wall centerlines, openings sized from the door/window schedules, storey
heights from the elevation datums, roof pitch and finishes. `planset-pdf.cjs`
does the extraction with `pdfjs-dist` (server side). On the reference set it
yields 3 storeys, all outlines closed, in ~3 s. Porting it gives Pascal "drop a
plan set, get the house" — the fastest path to a full building for v1.
