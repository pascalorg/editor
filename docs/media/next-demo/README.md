## Describe the demo accurately

Pascal Next is a hosted preview of the direction of the next Pascal editor. It
shows a detailed reconstruction of a real home with exploded view, cut view,
X-ray systems, a walkthrough, and interactive objects. These recordings do not
mean the hosted experience is already included in the open-source editor release.

Potential applications include facility management, home services, architecture,
home building, and infrastructure. The recordings do not establish a certified
LOD level or a measured reconstruction tolerance.
