# Gutter thumbnails

Generated with the built-in imagegen tool using roof-mounted editor screenshots and the existing gutter catalog icon. Final assets are transparent 256 × 256 WebP files in apps/editor/public/icons/gutter/.

## k-style

Reference: /tmp/gutter-k-style-reference.png

Use case: stylized-concept. Create a square transparent-background UI style thumbnail for a k-style rain gutter. Image 1 is a screenshot reference of the actual gutter mounted along the lower left roof eave: extract only that gutter, omit the roof, dormer opening, app UI and all other objects. Image 2 is the existing gutter catalog icon and is the style and camera reference. Match its lavender-purple smooth 3D miniature material, soft studio lighting, diagonal lower-left to upper-right orientation, orthographic three-quarter view from above, centered composition with generous transparent padding. Show a short open-topped K-style ogee gutter with a sculpted S-curve front fascia and folded lip, capped ends and a few slim straps across its open channel. Clearly distinguish the cross section. No downspout, no outlet holes, no text, no watermark, no background or ground shadow plane.
